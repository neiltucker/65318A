## Course Metadata

* **Course Number:** 65318A
* **Duration:** 2 Days (6 Modules)
* **Audience Level:** Advanced
* **Format:** Instructor-Led / Bootcamp

---

## Course Overview

This 2-day course builds on the SQL Server 2025 query analysis skills taught in 65317A and focuses on real-world troubleshooting techniques. Students will be taught to tune and optimize queries using native SQL Server features, SSMS 22 and other tools for SQL Server 2025.

### At Course Completion

After completing this course, you will be able to:

* Analyze query execution plans to identify performance bottlenecks in SQL Server 2025.
* Apply real-world tuning techniques using SSMS 22 and advanced diagnostic tools.
* Optimize query performance through index strategy and execution plan optimization.
* Troubleshoot and resolve performance issues in production SQL Server environments.
* Leverage SQL Server 2025 new features and Microsoft tools for continuous performance monitoring.

---

## Prerequisites

* Course 65317A - Querying and Analyzing SQL Server 2025, or equivalent knowledge.
* Solid understanding of T-SQL and query fundamentals.
* Experience working with SQL Server in production environments.

## Course Outline

### Module 1: Performance Troubleshooting Methodology
Establish a systematic approach to identifying and diagnosing SQL Server performance problems, establishing baselines, and applying a consistent workflow.
* **Duration:** 140 min
* **Lab:** Identifying a Slow Query

### Module 2: Advanced Index Tuning
Master index optimization strategies including missing index identification, maintenance strategies, and fragmentation management.
* **Duration:** 140 min
* **Lab:** Index Optimization

### Module 3: Query Store Performance Diagnostics
Leverage Query Store capabilities in SQL Server 2025 to analyze historical performance, identify regressions, and stabilize execution plans.
* **Duration:** 140 min
* **Lab:** Using Query Store for Troubleshooting

### Module 4: Wait Statistics and Resource Bottlenecks
Diagnose system-level performance problems by interpreting wait statistics and identifying CPU, I/O, and memory bottlenecks.
* **Duration:** 140 min
* **Lab:** Diagnosing Resource Bottlenecks

### Module 5: Concurrency and Blocking
Troubleshoot concurrency issues including blocking chains, deadlocks, and isolation level impacts on SQL Server 2025 workloads.
* **Duration:** 140 min
* **Lab:** Blocking and Deadlock Investigation

### Module 6: Advanced Query Optimization
Master advanced optimization techniques including parameter sniffing troubleshooting, plan stability, memory grants, and adaptive query processing.
* **Duration:** 140 min
* **Lab:** Parameter Sniffing Troubleshooting
